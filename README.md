# My Portfolio

A responsive React portfolio website built with Vite. Portfolio content is managed in one easy-to-edit file.

## Run locally

```powershell
cd frontend
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Customize

Edit [`frontend/src/data/portfolio.js`](./frontend/src/data/portfolio.js) to update the profile, project cards, skills, experience, phone, email, and social links. See [`frontend/README.md`](./frontend/README.md) for additional details.
